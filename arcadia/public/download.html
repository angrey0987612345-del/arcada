АРКАДИЯ: ЭОН РАДОСТИ

Установи игру как приложение на телефон или компьютер: своя иконка, полноэкранный режим, работает без интернета.

📲 Установить в один клик

🔌 Играть, даже если сайт выключен: установи приложение или скачай «Игру одним файлом» заранее. Одиночная игра, дуэли с ботом и сохранения работают без сервера; нужен он только для сетевой игры.

🤖 Android

Chrome · Яндекс · Samsung Internet
  1. Нажми «Установить приложение» выше.
  2. Или меню браузера ⋮ → «Установить приложение».
  3. Иконка Аркадии появится на главном экране.

🍏 iPhone и iPad

Safari
  1. Открой эту страницу в Safari.
  2. Нажми «Поделиться» (квадрат со стрелкой ⬆).
  3. Выбери «На экран Домой» → «Добавить».

💻 Компьютер (браузер)

Windows · macOS · Linux · Chromebook
  1. В Chrome, Edge или Яндекс Браузере нажми «Установить приложение».
  2. Или значок ⊕ в адресной строке.
  3. Аркадия откроется в своём окне, ярлык появится в меню «Пуск» / Dock.

🖥 Настольная версия (.zip)

Windows · macOS · Linux · Electron

Отдельная программа в своём окне, с сетевой игрой. Распакуй архив и запусти start-windows.bat (Windows) или start-mac-linux.sh (macOS/Linux). Нужен Node.js. Готовый установщик .exe / .dmg / .AppImage собирается командой npm run dist.

📶 Свой сервер по Wi-Fi

Твой компьютер = сервер · без интернета

Игра вместе по локальной сети. Компьютер раздаёт игру и сетевые комнаты, а друзья в той же Wi-Fi сети (или на точке доступа твоего телефона) открывают его адрес в браузере на телефоне или ПК. Распакуй архив и запусти start-server-windows.bat или start-server-mac-linux.sh. Нужен только Node.js, интернет не нужен.

🎮 Игра одним файлом

Любое устройство · без установки

Один HTML-файл. Он открывается в любом браузере без интернета. Сетевая игра в нём недоступна.

Перенос прогресса
