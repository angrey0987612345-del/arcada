# АРКАДИЯ: Эон Радости

Браузерная пошаговая RPG с гачей, дуэлями и кооперативом на 2–30 игроков.

## Структура
- `public/` — сама игра (`index.html`, `soul.js`, `soul.css`, `coop.js`, `export.js`, картинки и справочник механик).
- `netlify/functions/coop.mts` — сервер кооператива (комнаты и сообщения хранятся в Netlify Database).
- `netlify/functions/project-zip.mts` — выдаёт архив проекта для переноса на GitHub.
- `netlify/functions/desktop-app.mts` — собирает настольную версию (Electron) для Windows/macOS/Linux.
- `netlify/functions/local-server.mts` — выдаёт архив локального сервера (`/api/local-server`).
- `local-server/` — локальный сервер: компьютер игрока раздаёт игру и сетевые комнаты по Wi-Fi.
- `netlify/lib/zip.mts` — общий код для сборки ZIP-архивов.
- `public/manifest.webmanifest`, `public/sw.js`, `public/app.js`, `public/icons/` — игра как устанавливаемое приложение (PWA).
- `netlify/database/migrations/` — схема базы данных.

## Запуск
- Онлайн: подключите репозиторий к Netlify — настройки берутся из `netlify.toml`.
- Локально: `npm install`, затем `npx netlify dev`.
- Без сервера: кнопка «Скачать игру (HTML)» в меню даёт один файл, который открывается в браузере (сетевая игра в нём недоступна).

## Приложение для телефона и компьютера
Страница загрузки: `/download.html`, на неё ведёт кнопка «📲 Скачать приложение» в меню.
- Android, iPhone/iPad, Windows, macOS, Linux: игра ставится из браузера как приложение. У неё своя иконка и полноэкранный режим, после первой загрузки она работает без интернета.
- Настольная версия `.zip` (Electron): запуск через `start-windows.bat` или `start-mac-linux.sh`, установщик собирается командой `npm run dist`.

## Данные
Прогресс аккаунтов хранится в браузере. Кнопка «Скачать данные» сохраняет их в JSON, «Загрузить данные» — восстанавливает на другом устройстве.

## Игра по Wi-Fi: свой сервер на компьютере
`node local-server/server.mjs` (или `start-server-windows.bat` / `start-server-mac-linux.sh`). Компьютер становится сервером игры: друзья в той же Wi-Fi сети или на точке доступа телефона открывают показанный адрес (`http://192.168.x.x:8080/`) и играют вместе через «Сетевую игру». Интернет и онлайн-сайт не нужны, зависимостей нет — только Node.js 18+. Готовый архив с игрой: кнопка «Скачать локальный сервер» на странице загрузки.
